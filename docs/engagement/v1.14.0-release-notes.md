# Fettle v1.14.0: PR Advisory Evidence Hardening

Fettle v1.14.0 makes manifest-bound mutation evidence automatic on pull
requests while keeping it explicitly advisory and qualification-ineligible. It
also closes the application audit-hardening program without converting advisory
evidence into a full-corpus baseline or ratchet.

## What Changed

- Pull requests automatically run the changed-Python-scope mutation path, bound
  to the exact head, base, merge base, shard topology, and manifest digests.
- Aggregate reports state `aggregation_mode: "advisory"` and
  `qualification_eligible: false`. Full-corpus qualification remains
  `CLOSED_NON_PASS`; this release neither accepts a baseline nor waives
  survivors.
- Shard reports use attempt-scoped artifacts. A failed shard job may receive one
  bounded rerun, while aggregation still requires exactly one compatible
  completed attempt for every shard.
- Pull requests with no mutation-relevant Python scope dispatch no shards and
  publish retained, identity-bound `not_applicable` evidence only after the
  zero-scope identity validates.
- Heavy-module tests moved into bounded test modules without weakening required
  coverage. CI and release share fail-closed type and branch-coverage ratchets.
- The hardening changes landed through tree-equivalent squash commits that
  preserve protected `main`'s linear history. AH07 is closed with exact-tip main
  CI green through PRs #46, #47, and #48.

## Additional Changes

- The default runtime secret boundary covers Claude Code, Codex CLI, Gemini CLI,
  and OpenCode; supported output protection and unsupported host boundaries are
  reported explicitly.
- `fettle doctor` distinguishes installation, registration, trust, execution,
  and verification instead of treating registration as proof of execution.
- Contextual impact analysis remains advisory after its frozen promotion
  evaluation did not meet the required threshold.
- Stop-hook import and cross-file checks better support src-layout packages,
  project virtual environments, and package submodule imports.
- Rust and shell gate tests run on Ubuntu CI, Cargo resolves from `PATH`, and the
  README documents the seven plugin slash commands.
- The private-tool-dependent `effectiveness_report.py` was removed; any future
  effectiveness loop must use Fettle's own trace evidence.

## Compatibility and Deferred Work

- Removal of the `scripts` → `fettle/` compatibility symlink, previously planned
  for this minor, is deferred. The symlink remains in v1.14.0.
- Python 3.11 or later and Git remain required. Agent CLIs, Playwright browser
  binaries, services, and non-Python language toolchains remain external
  prerequisites.

## Upgrade

```bash
pipx upgrade finefettle
fettle doctor
```
